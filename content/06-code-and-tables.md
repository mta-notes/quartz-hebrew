## קוד בתוך משפט

כדי להריץ את האתר כותבים `./dev.sh` בטרמינל, ואת הגרסה בודקים עם `node --version`. קוד בתוך משפט מבודד מהטקסט שסביבו, כך שהוא לא מתפרק ולא מחליף צד עם המילים שלידו. גם קיצורי מקלדת: <kbd>Ctrl</kbd>+<kbd>K</kbd> פותח את החיפוש.

## בלוק קוד

בלוק קוד תמיד משמאל לימין ומיושר לשמאל, גם בעמוד עברי. הערות בעברית בתוכו נכתבות בגופן העברי:

```python title="binary_search.py"
def binary_search(items, target):
    """חיפוש בינארי ברשימה ממוינת. מחזיר אינדקס, או -1."""
    low, high = 0, len(items) - 1
    while low <= high:
        mid = (low + high) // 2  # האמצע
        if items[mid] == target:
            return mid
        if items[mid] < target:
            low = mid + 1        # ממשיכים בחצי הימני
        else:
            high = mid - 1       # ממשיכים בחצי השמאלי
    return -1
```

אפשר להדגיש שורות ומילים, ולמספר שורות:

```ts {3-4} showLineNumbers
export function greet(name: string) {
  const time = new Date().getHours()
  const hello = time < 12 ? "בוקר טוב" : "ערב טוב"
  return `${hello}, ${name}!`
}
```

כפתור ההעתקה מופיע כשמרחפים מעל הבלוק.

## טבלאות

| פעולה | פקודה | הערות |
| --- | --- | --- |
| הרצה מקומית | `./dev.sh` | נפתח ב-`localhost:8080` |
| בנייה לפרסום | `./build.sh` | נכתב ל-`public/` |
| שדרוג Quartz | שינוי `quartz-version.txt` | ואז מחיקת `quartz/` |
| Deploy | Automatic on push | תא באנגלית בלבד נשאר מיושר לימין |

טבלה רחבה מהמסך נגללת לצדדים בתוך התיבה שלה, ולא מרחיבה את כל העמוד.

| שם | ערך | יחידה | מינימום | מקסימום | ממוצע | הערות נוספות |
| --- | ---: | --- | ---: | ---: | ---: | --- |
| זמן טעינה | 120 | מילישניות | 80 | 300 | 140 | נמדד במחשב נייד |
| גודל הגופן העברי | 12 | KB | 12 | 12 | 12 | Heebo, רק האותיות העבריות |
| גודל עמוד | 45 | KB | 30 | 90 | 50 | כולל CSS ו-JavaScript |
