# Quartz בעברית

תבנית [Quartz](https://quartz.jzhao.xyz) 5 לאתרי תיעוד בעברית, מימין לשמאל מההתחלה ועד הסוף. כותבים Markdown בתיקייה `content/`, ומקבלים אתר עם רשימת פרקים, חיפוש, גרף קישורים, מצב כהה ותצוגה נוחה בטלפון.

## הרצה מקומית

צריך Node.js 22 ומעלה ו-Git.

```bash
./dev.sh
```

בפעם הראשונה הסקריפט מתקין את Quartz (בגרסה שב-`quartz-version.txt`) לתיקייה `quartz/`. האתר עולה ב-http://localhost:8080, ועמודים מתעדכנים בדפדפן מיד כששומרים.

אחרי שינוי ב-`theme/`, ב-`quartz.ts` או ב-`quartz.config.yaml`: עוצרים (Ctrl+C) ומריצים שוב.

## פרסום

`./build.sh` בונה את האתר לתיקייה `public/`. ב-GitHub, התהליך `.github/workflows/deploy.yml` עושה את זה בכל push ל-`main` ומפרסם ב-GitHub Pages. להפעלה: **Settings ← Pages ← Source: GitHub Actions**, ואז לעדכן את `baseUrl` ב-`quartz.config.yaml` ואת `repository` ב-`quartz.ts`.

## מה יש כאן

| קובץ | מה הוא עושה |
| --- | --- |
| `content/` | העמודים. שם הקובץ קובע את הסדר (`04-…` הוא פרק 04); `title`, `group` ו-`description` בראש הקובץ. |
| `quartz.ts` | הטקסטים והקישורים של האתר: עמוד הבית, הפוטר, הריפו ב-GitHub. |
| `quartz.config.yaml` | ההגדרות של Quartz: `locale: he-IL`, צבעים, גופנים, תוספים. |
| `theme/custom.scss` | כל העיצוב, במאפיינים לוגיים (`inline-start` במקום `left`). |
| `theme/components/` | הרכיבים: רשימת פרקים ומגירה, ראש עמוד, תוכן עניינים, פרק קודם/הבא, פוטר, 404. |
| `theme/transforms/` | עיבוד העמודים: כיוון לפסקאות באנגלית, כותרות הערה בעברית, עוגנים נגישים. |
| `theme/static/` | גופנים (Heebo, JetBrains Mono), לוגו ואייקון. |
| `scripts/` | מרכיבים את התבנית בתוך Quartz לפני כל בנייה. |

`quartz/` ו-`public/` לא נשמרים ב-Git. לשדרוג Quartz: משנים את `quartz-version.txt` ומוחקים את `quartz/`.

## מה מותאם לעברית

- **פריסה מימין לשמאל.** `locale: he-IL` גורם ל-Quartz לכתוב `dir="rtl"`, והרשת מתהפכת: רשימת הפרקים מימין, תוכן העניינים משמאל. כל מקום שבו Quartz או התוספים שלו כתבו `left`/`right` (ציטוטים, שורות קוד, תוצאות חיפוש, כפתור הגרף, פס הטעינה) מתוקן.
- **קוד ונוסחאות.** בלוקי קוד, קוד בתוך משפט ונוסחאות KaTeX תמיד משמאל לימין ומבודדים מהטקסט, כך שסוגריים לא מתהפכים. תוויות בתרשימי Mermaid בעברית.
- **פסקאות באנגלית.** פסקה שאין בה אף אות עברית מקבלת `dir="ltr"` (בשביל סימני הפיסוק) אבל נשארת מיושרת לימין. משפט עברי שמתחיל במילה באנגלית נשאר עברי, בניגוד ל-`dir="auto"`.
- **תיבות הערה.** הפס הצבעוני בצד ימין, כותרות ברירת המחדל בעברית ("טיפ", "אזהרה"), והחץ של תיבה מקופלת מצביע שמאלה.
- **טיפוגרפיה.** Heebo מוגש מהאתר (12KB לעברית), מרווח שורות רחב יותר, בלי UPPERCASE וריווח אותיות שלא מתאימים לעברית.
- **ניווט.** חצי "הבא" ו"הקודם" מצביעים לכיוון הקריאה, המגירה בטלפון נכנסת מימין, ו-Alt+← עובר לפרק הבא.
